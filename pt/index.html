// ANTES DE JOGAR OU PUBLICAR

StarHermit questões & respostas.

O que é StarHermit?

StarHermit é uma plataforma de distribuição e hospedagem de jogos para jogadores e criadores independentes. Jogue jogos de navegador gratuitos, compartilhe jogos do GitHub ou de uma versão local e conecte-se com amigos por meio de bate-papo e voz. É operado pela Hype Driven Development Inc. em Vancouver, British Columbia, Canadá.

Os jogos de navegador apresentados são gratuitos?

Sim. Os jogos vinculados no coleção de jogos de navegador estão livres para jogar. Escolha um jogo, faça login por meio de um provedor compatível, como Google ou GitHub, e aceite os Termos de Serviço para continuar. Você não precisa de um cartão de pagamento.

Preciso instalar alguma coisa?

Nenhuma instalação é necessária para jogos de navegador. Um opcional Cliente Windows está disponível para Windows 10 e 11.

Como faço para publicar um jogo de navegador?

Faça login no painel, escolha Adicionar jogo e envie um URL de repositório GitHub ou carregue uma versão de jogo local. Verifique o documentos do desenvolvedor para formatos suportados, serviços de hospedagem e jogos.

Posso vender um jogo no StarHermit?

A finalização da compra paga e os pagamentos do editor estão planejados e ainda não estão disponíveis. Você pode publicar e compartilhar jogos de navegador gratuitos hoje mesmo.

Quem pode criar uma conta?

A plataforma é destinada a pessoas que tenham pelo menos 18 anos e tenham atingido a maioridade legal no local onde residem. Leia o Termos de Serviço e política de Privacidade antes de criar uma conta.
