Δημοσιεύστε ένα παιχνίδι προγράμματος περιήγησης από ένα αποθετήριο GitHub ή ανεβάστε μια τοπική έκδοση. Συνδεθείτε στον πίνακα ελέγχου, επιλέξτε Προσθήκη παιχνιδιού και επιλέξτε την πηγή σας. Τα έγγραφα προγραμματιστή εξηγούν τις υποστηριζόμενες μορφές παιχνιδιών και τις επιλογές φιλοξενίας.

01

Επικολλήστε ένα Repo

Επιλέξτε Προσθήκη παιχνιδιού στον πίνακα ελέγχου και υποβάλετε ένα αποθετήριο GitHub που περιέχει ένα υποστηριζόμενο παιχνίδι προγράμματος περιήγησης ή ανεβάστε μια τοπική έκδοση. Το StarHermit φιλοξενεί τα αρχεία του παιχνιδιού και προσθέτει μια σελίδα παιχνιδιού στη βιβλιοθήκη. Τα παιχνίδια αποθετηρίου διατηρούν τον σύνδεσμο πηγής τους.

02

Διεκδικήστε το παιχνίδι σας

Συνδέστε τον λογαριασμό σας GitHub για να επαληθεύσετε την ιδιοκτησία του παιχνιδιού αποθετηρίου σας. Διαχειριστείτε το καλλιτεχνικό του έργο και την ανάπτυξή του από τον πίνακα εργαλείων και ανανεώστε το από έναν κλάδο ή δέσμευση. Τα παιχνίδια που ανεβαίνουν από μια τοπική έκδοση μπορούν να λαμβάνουν νέες μεταφορτώσεις αρχείων.

03

Οδικός χάρτης πληρωμών

Προγραμματίζονται πληρωμές ολοκλήρωσης αγοράς και εκδοτών. Ο στόχος είναι να υποστηριχθούν οι τιμές των παιχνιδιών, οι πωλήσεις και τα επίπεδα υποστήριξης μαζί με δωρεάν παιχνίδια, με πληρωμές με κάρτες και ψηφιακά στοιχεία. Αυτές οι λειτουργίες πληρωμής δεν είναι ακόμη διαθέσιμες.

StarHermit ερωτήσεις & απαντήσεις.

Τι είναι το StarHermit;

Το StarHermit είναι μια πλατφόρμα διανομής και φιλοξενίας παιχνιδιών για παίκτες και ανεξάρτητους δημιουργούς. Παίξτε δωρεάν παιχνίδια προγράμματος περιήγησης, μοιραστείτε παιχνίδια από το GitHub ή μια τοπική έκδοση και συνδεθείτε με φίλους μέσω συνομιλίας και φωνής. Λειτουργεί από την Hype Driven Development Inc. στο Βανκούβερ, Βρετανική Κολομβία, Καναδάς.

Τα επιλεγμένα παιχνίδια προγράμματος περιήγησης είναι δωρεάν;

Ναί. Τα παιχνίδια που συνδέονται στο συλλογή παιχνιδιών προγράμματος περιήγησης είναι ελεύθεροι να παίξουν. Επιλέξτε ένα παιχνίδι, συνδεθείτε μέσω ενός υποστηριζόμενου παρόχου όπως Google ή GitHub και αποδεχτείτε τους Όρους Παροχής Υπηρεσιών για να συνεχίσετε. Δεν χρειάζεστε κάρτα πληρωμής.

Χρειάζεται να εγκαταστήσω κάτι;

Δεν απαιτείται εγκατάσταση για παιχνίδια προγράμματος περιήγησης. Προαιρετικός πελάτες επιτραπέζιου υπολογιστή είναι διαθέσιμα για Windows 10 και 11, για macOS 11 και μεταγενέστερα και για Linux (x86_64).

Πώς μπορώ να δημοσιεύσω ένα παιχνίδι προγράμματος περιήγησης;

Συνδεθείτε στο ταμπλό, επιλέξτε Προσθήκη παιχνιδιού και, στη συνέχεια, υποβάλετε μια διεύθυνση URL αποθετηρίου GitHub ή ανεβάστε μια τοπική έκδοση παιχνιδιού. Ελέγξτε το έγγραφα προγραμματιστή για υποστηριζόμενες μορφές, φιλοξενία και υπηρεσίες παιχνιδιών.

Μπορώ να πουλήσω ένα παιχνίδι στο StarHermit;

Οι πληρωμές ολοκλήρωσης αγοράς και εκδοτών έχουν προγραμματιστεί και δεν είναι ακόμη διαθέσιμες. Μπορείτε να δημοσιεύσετε και να μοιραστείτε δωρεάν παιχνίδια προγράμματος περιήγησης σήμερα.

Ποιος μπορεί να δημιουργήσει λογαριασμό;

Η πλατφόρμα απευθύνεται σε άτομα που είναι τουλάχιστον 18 ετών και έχουν συμπληρώσει τη νόμιμη ενηλικίωση όπου ζουν. Διαβάστε το Όροι Παροχής Υπηρεσιών και Πολιτική Απορρήτου πριν δημιουργήσετε λογαριασμό.
