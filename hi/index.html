वाइब ने एक गेम कोड किया?

इसे यथावत प्रकाशित करें. निःशुल्क सर्वर एक्सेस प्राप्त करें और अपनी शर्तों पर पैसा कमाएँ।

साइन इन करें और क्लिक करें गेम जोड़ें.

प्रकाशित करने के लिए साइन इन करें डेवलपर विकी
बेहतर फ्रैमरेट्स के लिए मूल ग्राहक!
Windows के लिए डाउनलोड करें

Windows 10/11 · अहस्ताक्षरित निर्माण, इसलिए स्मार्टस्क्रीन आपसे पुष्टि करने के लिए कहेगा

Linux के लिए डाउनलोड करें

x86_64, glibc 2.35+ · साथ निकालें tar -xzf, फिर चलाएँ ./starhermit-client

macOS के लिए डाउनलोड करें

macOS 11+ · अहस्ताक्षरित बिल्ड, इसलिए पहली बार ऐप पर कंट्रोल-क्लिक करें और ओपन चुनें

Android के लिए डाउनलोड करें

Android 9+ · इस साइट से इंस्टॉल किया गया है, इसलिए Android के पूछने पर अपने ब्राउज़र को ऐप्स इंस्टॉल करने की अनुमति दें
