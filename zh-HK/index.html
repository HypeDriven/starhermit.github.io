StarHermit 問題 & 答案.

StarHermit是什麼？

StarHermit是一個面向玩家和獨立創作者的遊戲分發和託管平台。玩免費的瀏覽器遊戲，分享 GitHub 或本地版本的遊戲，並透過聊天和語音與朋友聯繫。它由位於加拿大不列顛哥倫比亞省溫哥華的 Hype Driven Development Inc. 營運。

特色瀏覽器遊戲是免費的嗎？

是的。連結中的遊戲 瀏覽器遊戲合集 可以免費玩。選擇遊戲，透過受支援的提供者（例如 Google 或 GitHub）登錄，然後接受服務條款以繼續。您不需要支付卡。

我需要安裝東西嗎？

瀏覽器遊戲無需安裝。選修的 桌面客戶端 適用於 Windows 10 和 11、macOS 11 及更高版本以及 Linux (x86_64)。

如何發布瀏覽器遊戲？

登入 儀表板，選擇“新增遊戲”，然後提交 GitHub 儲存庫 URL 或上傳本機遊戲版本。檢查 開發者文檔 了解支援的格式、託管和遊戲服務。

我可以在 StarHermit 上銷售遊戲嗎？

付費結帳和出版商付款已計劃中，但尚未提供。您今天可以發布和分享免費的瀏覽器遊戲。

誰可以建立帳戶？

此平台適用於年滿 18 歲且已達到居住地法定成年年齡的人士。閱讀 服務條款 和 隱私權政策 建立帳戶之前。
