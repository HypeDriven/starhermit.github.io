SYS.02 // UNTUK PENCIPTA

Publikasikan dalam hitungan menit.
Miliki selamanya.

Publikasikan game browser dari repositori GitHub atau unggah versi lokal. Masuk ke dasbor, pilih Tambahkan Game, dan pilih sumber Anda. Dokumen pengembang menjelaskan format permainan yang didukung dan opsi hosting.

01

Tempelkan Repo

Pilih Tambahkan Game di dasbor dan kirimkan repositori GitHub yang berisi game browser yang didukung, atau unggah versi lokal. StarHermit menghosting file game dan menambahkan halaman game ke perpustakaan. Game repositori mempertahankan tautan sumbernya.

02

Klaim Game Anda

Tautkan akun GitHub Anda untuk memverifikasi kepemilikan game repositori Anda. Kelola karya seni dan penerapannya dari dasbor, dan terapkan ulang dari cabang atau penerapan. Game yang diupload dari build lokal dapat menerima upload file baru.

03

Peta Jalan Pembayaran

Pembayaran berbayar dan pembayaran penerbit direncanakan. Tujuannya adalah untuk mendukung harga game, penjualan, dan tingkat pendukung serta game gratis, dengan pembayaran kartu dan aset digital. Fitur pembayaran ini belum tersedia.

// SEBELUM ANDA MAINKAN ATAU PUBLIKASIKAN

StarHermit pertanyaan & jawaban.

Apa itu StarHermit?

StarHermit adalah platform distribusi dan hosting game untuk pemain dan pencipta independen. Mainkan game browser gratis, bagikan game dari GitHub atau versi lokal, dan terhubung dengan teman melalui obrolan dan suara. Ini dioperasikan oleh Hype Driven Development Inc. di Vancouver, British Columbia, Kanada.

Apakah game browser unggulan ini gratis?

Ya. Permainan yang ditautkan di koleksi permainan peramban bebas untuk bermain. Pilih game, masuk melalui penyedia yang didukung seperti Google atau GitHub, dan terima Persyaratan Layanan untuk melanjutkan. Anda tidak memerlukan kartu pembayaran.

Apakah saya perlu menginstal sesuatu?

Game browser tidak perlu diinstal. Klien desktop opsional tersedia untuk Windows 10 dan 11 serta Linux (x86_64).

Bagaimana cara mempublikasikan game browser?

Masuk ke dasbor, pilih Tambahkan Game, lalu kirimkan URL repositori GitHub atau unggah build game lokal. Periksa dokumen pengembang untuk format yang didukung, hosting dan layanan game.

Bisakah saya menjual game di StarHermit?

Pembayaran berbayar dan pembayaran penerbit sudah direncanakan dan belum tersedia. Anda dapat mempublikasikan dan berbagi game browser gratis hari ini.

Siapa yang dapat membuat akun?

Platform ini diperuntukkan bagi orang-orang yang berusia minimal 18 tahun dan telah mencapai usia dewasa sah di tempat mereka tinggal. Baca Ketentuan Layanan Dan Kebijakan Privasi sebelum membuat akun.
