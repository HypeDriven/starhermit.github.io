1. 範圍同我哋係邊個

StarHermit 係由英屬哥倫比亞嘅一間公司 Hype Driven Development Inc. （「 StarHermit 」、「我哋」、「我哋」或者「我哋嘅」）營運。呢個政策適用於 starhermit.com 同埋連結到佢嘅網站、應用程式、 API 、寄存、遊戲發行、商業、社群同埋支援服務（統稱「平台」）。

呢個政策唔會管轄發佈者喺遊戲入面或者外部服務上面嘅自己數據做法。呢啲做法係由發佈者嘅私隱聲明所涵蓋。

2. 我哋收集嘅資料

帳戶同個人檔案資料

當你用 Google 登入或者連接其他帳戶，例如 GitHub ，我哋會收到供應商提供嘅資料，例如你嘅姓名、電郵地址、個人檔案圖片、用戶名同埋供應商帳戶識別碼。我哋收唔到你嘅 Google 或者 GitHub 密碼。我哋亦會收集你選擇加入嘅個人檔案詳情、偏好設定同設定。

平台同遊戲活動

我哋會收集運作你嘅圖書館同平台所需嘅資料，包括睇過、獲取、安裝、推出或者願望清單嘅遊戲；玩時間；雲端儲存；成就；排行榜；多人遊戲環節；朋友同存在；評論、評分、報告、訊息同其他內容；同埋遊戲透過 StarHermit 服務發送嘅技術事件。

開發人員同發佈者資料

如果你提交或者管理遊戲，我哋會收集存儲庫連結同元數據、構建、發佈同擁有記錄、團隊權限、儲存材料、 API 使用情況同埋通訊。為咗營利或者驗證，我哋亦可能會收集合法身分、商業、稅務、制裁、付款同埋付款資料。

交易

當你購物或者收到付款嗰陣，我哋會收集交易詳情，例如項目、金額、貨幣、時間、狀態、收據、退款同埋付款方式類型。卡同銀行詳情係由我哋嘅付款供應商處理，而唔係由 StarHermit 直接儲存。對於數碼資產交易，我哋可能會處理錢包地址同公開交易識別碼。

裝置、使用情況同通訊

我哋會自動接收 IP 位址、瀏覽器同裝置類型、操作系統、應用程式版本、語言、由 IP 衍生嘅大約位置、推薦頁面、識別碼、時間戳記、當機資料，同埋安全性同伺服器記錄等等嘅資料。我哋亦會收集你傳送嚟支援或者喺調查、意見、濫用報告同埋其他通訊入面嘅資料。

Cookie 同類似嘅技術

我哋會用 Cookie 、本機儲存空間同類似嘅技術嚟登入、偏好設定、安全性、防止欺詐、平台運作同埋評估。如果需要，我哋會喺使用非必要技術之前先要求同意。你嘅瀏覽器可能會畀你封鎖或者刪除佢哋，但係基本功能可能會停止運作。

我哋可能會用同我哋資訊主頁共用嘅實驗 Cookie 比較唔同嘅頁面設計。佢會記住顯示嘅設計長達90日，同埋測量瀏覽次數、集中瀏覽時間、登入完成同埋遊戲推出。另外一個標記會記住呢個瀏覽器已經登入咗最多一年。呢啲實驗活動唔包括你嘅電郵、帳戶識別碼或者登入憑證。

3. 我哋點樣用資訊

我哋會用個人資料嚟：

  • 建立同埋保護帳戶，驗證用戶，同埋提供平台功能；
  • 維護圖書館、權利、雲端儲存、社交功能、多人遊戲同支援；
  • 托管、建立、發行、推薦同埋評估遊戲同其他內容；
  • 處理購買、退款、稅項、欺詐檢查、出版商驗證同埋付款；
  • 發送交易、安全、法律同服務通訊；
  • 個人化同改善平台，診斷錯誤，同埋開發新功能；
  • 管理內容、執行我哋嘅條款、防止濫用，同埋保護使用者同平台；同
  • 遵守法律同埋建立、行使或者辯護法律索償。

視乎你住邊，我哋嘅法律基礎包括同你履行合約、遵守法律義務、你嘅同意，同埋我哋喺營運、保護同改善平台方面嘅合法利益。如果處理依賴同意，你可以隨時撤回同意。

4. 我哋點樣披露資料

我哋可能會向以下披露資料：

  • 服務供應商 提供托管、儲存、認證、分析、通訊、客戶支援、安全、內容交付、付款、稅務同支付服務；
  • 發佈者同其他用戶 當需要提供你要求嘅遊戲、交易、社交功能、報告或者其他互動嗰陣；
  • 專業顧問同權威人士 當為咗法律、監管、審計、安全或權利保護目的而合理必要嘅時候；
  • 商業交易參與者 關於融資、合併、收購、重組或資產出售，但須遵守適當保障措施；同
  • 其他人係你嘅指示或者你同意嘅情況下。

我哋唔會賣個人資料嚟賺錢，亦唔會用嚟做第三方跨上下文行為廣告。供應商會根據佢哋自己嘅條款同埋喺適用嘅情況下代表我哋處理資料。

個人檔案、用戶名、頭像、評論、指南、工作坊項目、排行榜項目、成就、遊戲頁面同埋你選擇發佈嘅其他內容可能會畀其他人睇到，亦可能會被索引或者重新分享。公開發佈個人資料嗰陣要小心。

遊戲可能會要求存取平台服務或者裝置功能，同埋可能會為發佈者收集資料。我哋要求發佈者披露佢哋嘅做法同埋遵守適用法律，但係發佈者對佢哋為咗自己嘅目的而收集嘅數據要獨立負責。玩之前睇吓遊戲嘅披露同權限要求。你可以用下面嘅聯絡資料向我哋報告你嘅疑慮。

6. 保留同國際轉移

我哋只會喺本政策所述目的合理必要嘅時間內保留個人資料，包括喺你嘅帳戶活躍嗰陣同埋根據安全性、備份、爭議、現有遊戲權利、稅務同會計記錄、防止欺詐同埋遵守法律嘅需要。保留期會因資料類型同適用要求而異。除非法律允許或者要求保留，否則我哋會喺唔再需要嘅時候刪除或者去識別資料。

StarHermit 同佢嘅供應商可能會喺加拿大、美國同其他國家處理資料。嗰度嘅私隱法可能同你住嘅地方唔同。喺需要嘅情況下，我哋會用合約同其他保障措施嚟進行國際轉移。

7. 安全性

我哋會採取合理嘅行政、技術同物理保障措施嚟保護個人資料，包括適合資料敏感性嘅存取控制同保護。冇一個系統係完全安全嘅，所以保護你嘅帳戶，同埋如果你懷疑未經授權嘅存取，請立即同我哋講。

你可以透過平台更新某啲帳戶詳情同私隱設定、斷開連結服務、管理瀏覽器儲存空間，同埋用訊息入面嘅連結取消訂閱市場推廣電郵。你仍然會收到必要嘅服務、保安同法律通知。

視乎你嘅位置，你可能有權存取、更正、刪除或者取得你嘅個人資料副本；撤回同意；限制或者反對處理；或者向私隱監管機構投訴。你亦可能有權獲得有關對你有重大影響嘅自動決策嘅資訊。我哋可能需要驗證你嘅身分，同埋可能會喺法律允許或者要求嘅情況下保留資料。

我哋可能會隨住平台或者法律嘅變動更新呢個政策。我哋會發佈修訂後嘅政策同埋更新生效日期。如果有重大變動，我哋會喺適當或者需要嘅情況下提供額外通知。
