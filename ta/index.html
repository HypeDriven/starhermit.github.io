02

உங்கள் விளையாட்டைக் கோருங்கள்

உங்கள் களஞ்சிய விளையாட்டின் உரிமையைச் சரிபார்க்க, உங்கள் GitHub கணக்கை இணைக்கவும். டாஷ்போர்டிலிருந்து அதன் கலைப்படைப்பு மற்றும் வரிசைப்படுத்தலை நிர்வகிக்கவும், ஒரு கிளையில் இருந்து மீண்டும் வரிசைப்படுத்தவும். உள்ளூர் உருவாக்கத்திலிருந்து பதிவேற்றப்படும் கேம்கள் புதிய கோப்பு பதிவேற்றங்களைப் பெறலாம்.

03

பணம் செலுத்தும் பாதை வரைபடம்

பணம் செலுத்திய செக்அவுட் மற்றும் வெளியீட்டாளர் பேஅவுட்கள் திட்டமிடப்பட்டுள்ளன. கார்டு மற்றும் டிஜிட்டல் சொத்துக் கட்டணங்களுடன் இலவச கேம்களுடன் கேம் விலை, விற்பனை மற்றும் ஆதரவாளர் அடுக்குகளை ஆதரிப்பதே குறிக்கோள். இந்த கட்டண அம்சங்கள் இன்னும் கிடைக்கவில்லை.

// திட்டமிடப்பட்ட கொடுப்பனவுகள்

சுயாதீன படைப்பாளர்களுக்கான கட்டண அடுக்கு.

எங்கள் சாலை வரைபடத்தில் கீழே உள்ள திறன்கள் உள்ளன. செக்அவுட், பணத்தைத் திரும்பப் பெறுதல் மற்றும் வெளியீட்டாளர் செலுத்துதல்கள் இன்னும் கிடைக்கவில்லை.

அட்டைகள் & பிராந்தியமானது

வீரர்கள் தங்கள் உள்ளூர் நாணயத்தில் முக்கிய கிரெடிட் மற்றும் டெபிட் கார்டுகளைப் பார்க்கிறார்கள் - பிராந்திய விலை ஆதரவு, சேமிக்கப்பட்ட கட்டண முறைகள் மற்றும் உடனடி ரசீதுகள் ஆகியவை அடங்கும்.

கிரிப்டோகரன்சி

செக் அவுட்டில் முக்கிய கிரிப்டோகரன்ஸிகளை ஏற்கவும். வீரர்கள் தங்கள் பணப்பையில் இருந்து பணம் செலுத்துகிறார்கள்; நீங்கள் கிரிப்டோவில் குடியேறவும் அல்லது ஃபியட்டிற்கு தானாக மாற்றவும் தேர்வு செய்கிறீர்கள் - உங்கள் அழைப்பு, ஒரு பேஅவுட்.

  • பணத்தைத் திரும்பப் பெறுதல் & பிளாட்ஃபார்ம் மூலம் வசூலிக்கப்படும் கட்டணம் - நீங்கள் ஒருபோதும் தகராறுகளைத் தனியாக எதிர்த்துப் போராட முடியாது
  • உங்கள் கணக்காளருக்கு ஏற்றுமதி செய்யக்கூடிய பதிவுகளுடன் திட்டமிடப்பட்ட பேஅவுட்கள்
  • விற்பனை வரி, VAT மற்றும் கிரிப்டோ அறிக்கையிடல் இயங்குதள அளவில் கணக்கிடப்படுகிறது
  • பிராந்தியம், நாணயம் மற்றும் கட்டண முறை ஆகியவற்றின் அடிப்படையில் டாஷ்போர்டு முறிவுகள்

// நிர்வகிக்கப்பட்ட பின்தளம், ஜீரோ டெவொப்ஸ்

கன்சோல் தர உள்கட்டமைப்பு, பெட்டிக்கு வெளியே.

உரிமைகோரப்பட்ட கேம்கள் நிர்வகிக்கப்பட்ட சேவைகளுக்கான அணுகலைப் பெறுகின்றன, அவை வழக்கமாக பல மாதங்கள் பொறியியல் மற்றும் சர்வர் பில் பொருந்தும்.

மல்டிபிளேயர் ரிலே & ஹோஸ்டிங்

உங்கள் சொந்த ஹோஸ்டிங் உள்கட்டமைப்பை நிர்வகிக்காமல் பிளேயர்களை இணைக்க, பிளாட்ஃபார்மின் பியர் ரிலே அல்லது ஹோஸ்ட் செய்யப்பட்ட கேம் அமர்வுகளை ஒருங்கிணைக்கவும்.

லீடர்போர்டுகள்

தளத்தின் லீடர்போர்டு API உடன் மதிப்பெண் சமர்ப்பிப்பு மற்றும் தரவரிசை காட்சிகளை ஒருங்கிணைக்கவும்.

மேட்ச்மேக்கிங்

பகிரப்பட்ட இயங்குதள சேவைகள் மூலம் மேட்ச்மேக்கிங் வரிசைகள் மற்றும் கேம் அமர்வுகளை ஒருங்கிணைக்கவும்.

கிளவுட் சேமிக்கிறது

கிளவுட்-சேவ் ஏபிஐ மூலம் ஒவ்வொரு பிளேயருக்கும் சேமித்த தரவைச் சேமிக்கவும், எனவே ஆதரிக்கப்படும் கேம்கள் சாதனங்கள் முழுவதும் மீண்டும் முன்னேற முடியும்.

சாதனைகள் & புள்ளிவிவரங்கள்

பிளேயர் மைல்ஸ்டோன்கள், முன்னேற்றம் மற்றும் மொத்த பகுப்பாய்வுகளை பெட்டிக்கு வெளியே கண்காணிக்கவும்.

இருப்பு & நண்பர்கள்

StarHermit சமூக வரைபடத்தில் தானாக இணைக்கப்பட்ட சிறந்த நிலை, அழைப்புகள் மற்றும் சேர-விளையாட்டு ஹூக்குகள்.

பொழுதுபோக்கு ஆர்வலர்கள் மற்றும் சுயாதீன படைப்பாளிகள் GitHub களஞ்சியம் அல்லது உள்ளூர் உருவாக்கம் மூலம் உலாவி விளையாட்டை பிளேயர்களுக்கு கொண்டு வர முடியும். ஹோஸ்டிங் மற்றும் பகிரப்பட்ட கேம் சேவைகள் உங்கள் விளையாட்டில் கவனம் செலுத்த உதவும். களஞ்சிய உரிமையானது, குறியீட்டை எழுதிய நபர்களுடன் கிரெடிட்டை இணைக்கிறது.

உலாவி விளையாட்டைக் கொண்டு வாருங்கள். கேமைச் சேர் → களஞ்சியத்தைத் தேர்வு செய்யவும் அல்லது உள்ளூர் உருவாக்கம் → வெளியிடவும்.

டாஷ்போர்டில் இருந்து வெளியிடவும் டாக்ஸைப் படியுங்கள்

இணையம் இங்கே தொடங்குங்கள்

நிறுவ எதுவும் இல்லை. உங்கள் உலாவியில் உங்கள் நூலகம், நண்பர்கள், அரட்டை மற்றும் குரல் — ஆதரிக்கப்படும் உள்நுழைவு வழங்குநரைத் தேர்வுசெய்து, நீங்கள் உள்ளீர்கள்.

Windows

StarHermit என்றால் என்ன?

StarHermit என்பது வீரர்கள் மற்றும் சுயாதீன படைப்பாளர்களுக்கான விளையாட்டு விநியோகம் மற்றும் ஹோஸ்டிங் தளமாகும். இலவச உலாவி கேம்களை விளையாடுங்கள், GitHub அல்லது உள்ளூர் உருவாக்கத்தில் இருந்து கேம்களைப் பகிரலாம் மற்றும் அரட்டை மற்றும் குரல் மூலம் நண்பர்களுடன் இணையலாம். இது கனடாவின் பிரிட்டிஷ் கொலம்பியாவில் உள்ள வான்கூவரில் Hype Driven Development Inc. ஆல் இயக்கப்படுகிறது.

சிறப்பு உலாவி கேம்கள் இலவசமா?

ஆம். விளையாட்டுகள் இணைக்கப்பட்டுள்ளன உலாவி விளையாட்டு சேகரிப்பு விளையாட இலவசம். ஒரு கேமைத் தேர்வுசெய்து, Google அல்லது GitHub போன்ற ஆதரிக்கப்படும் வழங்குநர் மூலம் உள்நுழைந்து, தொடர சேவை விதிமுறைகளை ஏற்கவும். உங்களுக்கு கட்டண அட்டை தேவையில்லை.

நான் எதையும் நிறுவ வேண்டுமா?

உலாவி விளையாட்டுகளுக்கு நிறுவல் தேவையில்லை. விருப்பமானது டெஸ்க்டாப் வாடிக்கையாளர்கள் Windows 10 மற்றும் 11 க்கும், macOS 11 மற்றும் அதற்குப் பிறகும், Linux (x86_64) க்கும் கிடைக்கும்.

உலாவி விளையாட்டை எவ்வாறு வெளியிடுவது?

இல் உள்நுழையவும் டாஷ்போர்டு, விளையாட்டைச் சேர் என்பதைத் தேர்வுசெய்து, GitHub களஞ்சிய URL ஐச் சமர்ப்பிக்கவும் அல்லது உள்ளூர் கேம் உருவாக்கத்தைப் பதிவேற்றவும். சரிபார்க்கவும் டெவலப்பர் டாக்ஸ் ஆதரிக்கப்படும் வடிவங்கள், ஹோஸ்டிங் மற்றும் கேம் சேவைகளுக்கு.
