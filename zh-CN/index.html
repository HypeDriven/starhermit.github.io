StarHermit 问题 & 答案.

星隐者是什么？

StarHermit是一个面向玩家和独立创作者的游戏分发和托管平台。玩免费的浏览器游戏，从 GitHub 或本地版本共享游戏，并通过聊天和语音与朋友联系。它由位于加拿大不列颠哥伦比亚省温哥华市的 Hype Driven Development Inc. 运营。

特色浏览器游戏是免费的吗？

是的。链接中的游戏 浏览器游戏合集 可以免费玩。选择一个游戏，通过受支持的提供商（例如 Google 或 GitHub）登录，然后接受服务条款以继续。您不需要支付卡。

我需要安装什么东西吗？

浏览器游戏无需安装。可选的 Windows客户端 适用于 Windows 10 和 11。

如何发布浏览器游戏？

登录到 仪表板，选择“添加游戏”，然后提交 GitHub 存储库 URL 或上传本地游戏版本。检查 开发者文档 了解支持的格式、托管和游戏服务。

我可以在 StarHermit 上出售游戏吗？

付费结帐和出版商付款已计划中，但尚未提供。您今天可以发布和分享免费的浏览器游戏。

谁可以创建帐户？

该平台适用于年满 18 岁且已达到居住地法定成年年龄的人士。阅读 服务条款 和 隐私政策 创建帐户之前。
