01

Enganxeu un Repo

Trieu Afegeix un joc al tauler i envieu un repositori GitHub que contingui un joc de navegador compatible o pengeu una compilació local. StarHermit allotja els fitxers del joc i afegeix una pàgina del joc a la biblioteca. Els jocs del dipòsit conserven el seu enllaç d'origen.

02

Reclama el teu joc

Enllaceu el vostre compte GitHub per verificar la propietat del vostre joc del dipòsit. Gestioneu la seva il·lustració i el desplegament des del tauler i torneu a desplegar des d'una sucursal o commit. Els jocs penjats des d'una compilació local poden rebre nous fitxers carregats.

03

Full de ruta de pagaments

Es planifiquen els pagaments de pagament i els pagaments dels editors. L'objectiu és donar suport als preus dels jocs, les vendes i els nivells de suport al costat de jocs gratuïts, amb pagaments amb targeta i actius digitals. Aquestes funcions de pagament encara no estan disponibles.

// ABANS DE JUGAR O PUBLICAR

StarHermit preguntes & respostes.

Què és StarHermit?

StarHermit és una plataforma de distribució i allotjament de jocs per a jugadors i creadors independents. Juga a jocs de navegador gratuïts, comparteix jocs de GitHub o d'una versió local i connecta't amb els amics mitjançant el xat i la veu. Està operat per Hype Driven Development Inc. a Vancouver, Colúmbia Britànica, Canadà.

Els jocs de navegador destacats són gratuïts?

Sí. Els jocs enllaçats al col·lecció de jocs de navegador són lliures de jugar. Trieu un joc, inicieu la sessió a través d'un proveïdor compatible com Google o GitHub i accepta les Condicions del servei per continuar. No necessiteu una targeta de pagament.

Necessito instal·lar alguna cosa?

No cal instal·lació per als jocs de navegador. Opcional clients d'escriptori estan disponibles per a Windows 10 i 11, per a macOS 11 i posteriors i per a Linux (x86_64).

Com puc publicar un joc de navegador?

Inicieu la sessió a quadre de comandament, trieu Afegeix un joc i, a continuació, envieu un URL de repositori GitHub o pengeu una compilació de joc local. Comproveu el documents del desenvolupador per als formats compatibles, allotjament i serveis de jocs.

Puc vendre un joc a StarHermit?

Els pagaments de pagament i els pagaments dels editors estan planificats i encara no estan disponibles. Podeu publicar i compartir jocs de navegador gratuïts avui mateix.

Qui pot crear un compte?

La plataforma és per a persones que tinguin almenys 18 anys i hagin complert la majoria d'edat legal on viuen. Llegeix el Condicions del servei i Política de privadesa abans de crear un compte.
