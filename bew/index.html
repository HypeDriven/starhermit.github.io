SYS.02 // BUAT PENCIPTA

Publikasiin game browser dari repositori GitHub atau upload build lokal. Masuk ke dasbor, pilih Tambah Game, dan pilih sumber lu. Dokumen pengembang menjelaskan format game yang didukung dan opsi hosting.

01

Tempelin Repo

Pilih Tambahin Game di dasbor dan kirim repositori GitHub yang isinya game browser yang didukung, atau upload build lokal. StarHermit ngehost file game dan nambahin halaman game ke perpustakaan. Game repositori mempertahankan tautan sumber mereka.

02

Klaim Game lu

Tabungin akun GitHub lu buat ngeverifikasi kepemilikan game repositori lu. Kelola karya seni dan penyebaran dari dasbor, dan penyebaran ulang dari cabang atau komitmen. Game yang diunggah dari bangunan lokal bisa nerima unggahan file baru.

03

Peta Jalan Pembayaran

Pembayaran berbayar dan pembayaran penerbit direncanakan. Tujuannye adalah untuk mendukung harga game, penjualan, dan tingkat pendukung di samping game gratis, dengan pembayaran kartu dan aset digital. Fitur pembayaran ini belom tersedia.

Tumpukan pembayaran buat pencipta independen.

Pemain ngecek dengan kartu kredit dan debit utama dalam mata uang lokal mereka — dukungan harga regional, metode pembayaran yang disimpan, dan penerimaan instan termasuk.

Mata uang kripto

Terima mata uang kripto utama pas masir. Pemain bayar dari dompet mereka; lu milih buat nyetel di kripto atau otomatis konversi ke fiat — panggilan lu, per pembayaran.

  • Pengembalian dana & chargeback yang diproses oleh platform — lu kagak pernah ngelawan sengketa sendirian
  • Pembayaran yang dijadwalkan dengan catatan yang bisa diekspor buat akuntan lu
  • Pajak penjualan, PPN, dan pelaporan kripto dihitung di tingkat platform
  • Rincian dasbor berdasarkan wilayah, mata uang, dan metode pembayaran

// SEBELUM LO MAIN ATAU TERBITIN

StarHermit pertanyaan & jawaban.

Apa itu StarHermit?

StarHermit adalah platform distribusi dan hosting game untuk pemain dan pencipta independen. Main game browser gratis, bagiin game dari GitHub atau build lokal, dan nyambung ama temen lewat obrolan dan suara. Itu dioperasiin oleh Hype Driven Development Inc. di Vancouver, British Columbia, Kanada.

Apakah game browser yang ditampilkan gratis?

Iye. Game yang terhubung di koleksi game browser bebas buat maen. Pilih game, masuk lewat penyedia yang didukung seperti Google atau GitHub, dan terima Ketentuan Layanan untuk melanjutkan. Lu kagak perlu kartu pembayaran.

Apa perlu gue pasang apa aja?

Gak perlu instalasi buat game browser. Mana suka klien desktop tersedia untuk Windows 10 dan 11, untuk macOS 11 dan lebih baru, dan untuk Linux (x86_64).

Gimane caranya gue nerbitin game browser?

Masuk ke dasbor, pilih Tambahin Game, trus kirim URL repositori GitHub atau unggah build game lokal. Cek dokumen pengembang untuk format yang didukung, hosting dan layanan game.

Apa gue bisa jual game di StarHermit?

Pembayaran berbayar dan penerbit udah direncanain dan belom tersedia. Lu bisa nerbitin dan bagiin game browser gratis hari ini.

Siapa yang bisa bikin akun?

Platform ini buat orang yang umurnye minimal 18 dan udah nyampe usia mayoritas hukum di tempat mereka tinggal. Baca Syarat Layanan ame Kebijakan Privasi sebelum bikin akun.
