SYS.02 // FOR CREATORS

Publish in minutes.
Own it forever.

Publish a browser game from a GitHub repository or upload a local build. Sign in to the dashboard, choose Add Game, and select your source. The developer docs explain supported game formats and hosting options.

01

Paste a Repo

Choose Add Game in the dashboard and submit a GitHub repository containing a supported browser game, or upload a local build. StarHermit hosts the game files and adds a game page to the library. Repository games retain their source link.

02

Claim Your Game

Link your GitHub account to verify ownership of your repository game. Manage its artwork and deployment from the dashboard, and redeploy from a branch or commit. Games uploaded from a local build can receive new file uploads.

03

Payments Roadmap

Paid checkout and publisher payouts are planned. The goal is to support game pricing, sales and supporter tiers alongside free games, with card and digital-asset payments. These payment features are not available yet.

// BEFORE YOU PLAY OR PUBLISH

StarHermit questions & answers.

What is StarHermit?

StarHermit is a game distribution and hosting platform for players and independent creators. Play free browser games, share games from GitHub or a local build, and connect with friends through chat and voice. It is operated by Hype Driven Development Inc. in Vancouver, British Columbia, Canada.

Are the featured browser games free?

Yes. The games linked in the browser game collection are free to play. Choose a game, sign in through a supported provider such as Google or GitHub, and accept the Terms of Service to continue. You do not need a payment card.

Do I need to install anything?

No installation is needed for browser games. An optional Windows client is available for Windows 10 and 11.

How do I publish a browser game?

Sign in to the dashboard, choose Add Game, then submit a GitHub repository URL or upload a local game build. Check the developer docs for supported formats, hosting and game services.

Can I sell a game on StarHermit?

Paid checkout and publisher payouts are planned and are not available yet. You can publish and share free browser games today.

Who can create an account?

The platform is for people who are at least 18 and have reached the age of legal majority where they live. Read the Terms of Service and Privacy Policy before creating an account.
