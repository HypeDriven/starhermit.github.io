Naon StarHermit?

StarHermit mangrupikeun distribusi kaulinan sareng platform hosting pikeun pamaén sareng panyipta mandiri. Maén kaulinan browser bébas, babagi kaulinan tina GitHub atawa wangunan lokal, tur sambungkeun ka babaturan ngaliwatan obrolan jeung sora. Dioperasikeun ku Hype Driven Development Inc. di Vancouver, British Columbia, Kanada.

Naha kaulinan browser anu diulas gratis?

Sumuhun. Kaulinan numbu dina kumpulan kaulinan browser bebas muter . Milih kaulinan, asup ngaliwatan panyadia dirojong kayaning Google atanapi GitHub, sarta nampa Sarat Service neruskeun. Anjeun teu kedah kartu pamayaran.

Naha kuring kudu masang nanaon?

Taya instalasi diperlukeun pikeun kaulinan browser. Pilihan klien desktop sadia pikeun Windows 10 jeung 11, pikeun macOS 11 sarta engké, jeung Linux (x86_64).

Kumaha kuring nyebarkeun kaulinan browser?

Asup ka dasbor, Pilih Tambahkeun Game, lajeng ngalebetkeun URL Repository GitHub atanapi unggah hiji ngawangun kaulinan lokal. Pariksa docs pamekar pikeun format dirojong, hosting jeung jasa kaulinan.

Pamayaran mayar sareng pangmayaran penerbit direncanakeun sareng henteu acan sayogi. Anjeun tiasa nyebarkeun sareng ngabagi kaulinan browser gratis ayeuna.
