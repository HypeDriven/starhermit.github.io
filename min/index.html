SYS.01 // UNTUAK PAMAIN .

Koleksi awak, di tangah
dari alam semesta.

Cari pamainan palayar gratis di saluruah strategi, balap, RPG, teka-teki jo simulasi. Simpan perpustakaan jo kawan-kawan basamo-samo di dasbor web atau klien Windows, macOS jo Linux.

Pustaka Pamainan Panjalajah Gratis

Pamainan mandiri jo proyek eksperimen, dari strategi jo penembak sampai RPG, balap, teka-teki jo sim nan nyaman. Piliah pamainan dan mulai dari browser Sanak.

Gratis untuak mamulai

Buek akun malalui panyadio masuak nan didukuang dan mainkan pamainan browser nan ditampilkan sacaro gratis. Indak ado kartu pambayaran dan indak ado pamasangan game tapisah.

Web, Windows, macOS & Linux

Gunoan dasbor web untuak maluncuakan pamainan palayar, atau opsional Windows, macOS atau Linux klien untuak mangalola perpustakaan jo instalasi lokal Sanak. Pamainan nan didukuang dapek manggunoan simpanan awan.

Dibangun di ateh Masyarakaik

Tambah kawan, caliak kahadirannyo, dan hubungi malalui obrolan teks jo suaro. Rating pamain mambantu Sanak manamukan pamainan nan dinikmati urang lain.

Tamukan Pamainan Mandiri

Cubolah genre baru atau pambuek nan alun dikenal. Koleksi permainan browser gratis maagiah Sanak tampek untuak manjalajah tanpa mambali.

Layanan Pamainan Basamo

Pamainan dapek mangintegrasikan prestasi, papan rangking, multipamain jo kaadaan pamain malalui layanan basamo StarHermit. Fitur nan tasadio tagantuang pado integrasi satiok pamainan.

Mulailah jo pamainan browser gratis — masuak, piliah pamainan, jo main.

SYS.02 // UNTUAK PANCIPTA

Publikasikan dalam hitungan minik.
Milikilah salamonyo.

Tabikkan pamainan palayar dari gudang GitHub atau maunggah bangunan lokal. Masuak ka dasbor, piliah Tambah Permainan, dan piliah sumber Sanak. Dokumen pengembang manjalehan format pamainan nan didukuang jo piliahan hosting.

01

Tempelkan Repo

Piliah Tambah Pamainan di dasbor dan kirimkan repositori GitHub nan manganduang pamainan palayar nan didukuang, atau unggah bangunan lokal. StarHermit manjadi tuan rumah file-file pamainan jo manambahkan laman pamainan ka pustaka. Pamainan gudang mampatahankan tautan sumbernyo.

02

Klaim Pamainan Sanak

Hubungkan akun GitHub Sanak untuak mamverifikasi kapamilikan pamainan gudang Sanak. Mangalola karya seni jo panyabarannyo dari dasbor, jo panyabaran baliak dari suatu cabang atau komit. Pamainan nan diunggah dari bangunan lokal dapek manarimo unggahan berkas baru.

03

Peta Jalan Pambayaran

Checkout dibayia jo pambayaran penerbit direncanakan. Tujuannyo adolah untuak mandukuang panatapan harago pamainan, panjualan jo tingkat pandukuang di sampiang pamainan gratis, jo pambayaran kartu jo digital-aset. Fitur pambayaran ko alun tasadio lai.

// PAMBAYARAN NAN DIRENCANAKAN

Sabuah tumpukan pambayaran untuak pambuek mandiri.

Peta jalan awak tamasuak kamampuan di bawah ko. Checkout, pengembalian dana jo pambayaran penerbit alun tasadio lai.

Pamain mancaliak jo kartu kredit jo debit utamo dalam mata uang lokalnyo — dukuangan panatapan harago daerah, caro pambayaran nan disimpan, jo panarimoan instan dimasuakkan.

Mata uang kripto

Tarimo mata uang kripto gadang pado wakatu mambayia. Pamain mambayia dari dompetnyo; sanak mamiliah untuak manatap di kripto atau otomatis maubah ka fiat — panggilan sanak, per pambayaran.

// SABALUN ANG MAIN ATAU PUBLIK

StarHermit tanyo & jawaban.

Apo itu StarHermit?

StarHermit adolah platform distribusi jo panyatuan pamainan untuak pamain jo pambuek mandiri. Mainkan pamainan palayar gratis, bagikan pamainan dari GitHub atau bangunan lokal, jo mahubuangkan jo kawan-kawan malalui obrolan jo suaro. Inyo dioperasikan dek Hype Driven Development Inc. di Vancouver, Kolombia Inggirih, Kanada.

Apokah permainan browser nan ditampilkan tu gratis?

Iyo. Pamainan nan takaik di koleksi pamainan palayar adolah bebas untuak main. Piliah pamainan, masuak malalui panyadio nan didukuang sarupo Google atau GitHub, dan tarimo Katantuan Layanan untuak malanjuikan. Indak paralu kartu pambayaran.

Apo paralu ambo pasang apo-apo?

Indak paralu pamasangan untuak pamainan palayar. Opsional klien meja ado untuak Windows 10 jo 11, untuak macOS 11 dan kamudian, dan untuak Linux (x86_64).

Baa caronyo manabikkan permainan browser?

Masuak ka dasbor, piliah Tambah Pamainan, kamudian kirimkan URL gudang GitHub atau unggah bangunan pamainan lokal. Pareso nan dokumen pengembang untuak format nan didukuang, layanan hosting jo pamainan.

Lai buliah ambo manjua game di StarHermit?

Checkout jo pambayaran penerbit nan dibayia alah direncanakan dan alun tasadio. Sanak dapek manabikan jo mambagikan pamainan palayar gratis hari ko.

Sia nan bisa mambuek akun?

Platform ko untuak urang nan paliang indak baumua 18 tahun dan alah mancapai umua mayoritas hukum di tampek inyo tingga. Bacolah Katantuan Layanan jo Kabijakan privasi sabalun mambuek akun.
